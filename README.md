🧥 Desktop Digital Wardrobe Manager
A desktop GUI application built with Python to help users digitally organize, manage, and style their wardrobe. Features automated background removal, a drag-and-drop canvas interface, and a persistent PostgreSQL database backend.

✨ Key Features
Automated Image Background Removal: Utilizes rembg to automatically strip backgrounds from clothing photos before saving them to the wardrobe directory.

Interactive Drag-and-Drop Canvas: Freely arrange clothing items on a custom canvas layout to test and visualize outfits.

PostgreSQL Database Integration: Securely stores clothing metadata, file paths, and item attributes in a relational database.

Dynamic GUI Management: Built with wxPython for a responsive desktop interface complete with right-click context menus for easy item deletion and inventory management.

🛠️ Tech Stack
Language: Python

GUI Framework: wxPython

Image Processing: rembg

Database: PostgreSQL
